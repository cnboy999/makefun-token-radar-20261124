The best token launch radar: a program that reads a frozen DefiLlama snapshot of 758 protocols, ranks 200 of them by the implied value of a token they have not issued yet, and shows how to farm each one. The model (radar-2) weights token likelihood from TVL, 7-day growth, age and chain breadth, excludes exchanges and wrapped/staked products that will never airdrop, and gives every protocol an 8-step farm plan with costs and times. The dashboard is a sortable, filterable board with a detail view per protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
